# Customer Segmentation & Retention Analysis (RFM Framework)

## Problem Statement
Businesses often struggle to identify which customers drive the most value and which are at risk of churn.
This project segments customers based on purchasing behavior to support data-driven retention and
reactivation strategies.

## Dataset
Transactional retail dataset containing customer purchase history including invoice dates,
quantities, and monetary values.

## Approach
- Data cleaning and preprocessing
- RFM (Recency, Frequency, Monetary) feature engineering
- Customer segmentation using RFM scoring
- Business interpretation of customer segments

## Tools Used
- SQL
- Python (pandas, numpy, matplotlib)
- Microsoft Excel

## Status
Analysis in progress.
